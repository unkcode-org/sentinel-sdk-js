# RUM-7E security and privacy review — implementation stage

Result: implementation approved and tested; **rollout remains blocked** by the RUM-7F marker, RUM-7C real E2E, and the clock-skew freshness issue described in `implementation-summary.md`. The independent privacy contract is `privacy-contract.md`.

Threats and controls: a public key is visible and must remain a Bearer identifier, never a secret or log field; Ingest remains authority for exact Origin, credential RUM permission and environment policy. Browser cannot infer authorization from OPTIONS or frontend config. Generate UUIDs with secure crypto; retain the existing RUM session ID. Build replay URL from the validated Ingest base without query/fragment and exclude it from OTel fetch instrumentation. Sanitize rrweb events before memory retention; reject unknown shapes and prototype keys; never log raw events/chunks/DOM, URLs with queries, credentials, or payload-bearing exceptions. Do not read cookies/storage values. Bound event traversal, per-event size, whole JSON body, queue count, retry count and elapsed time. Use one in-flight upload, frozen bodies, abort on teardown, and only 202 confirmation. Do not use beacon/unload acknowledgement. Revalidate fresh policy on refresh and before each upload; server remains final authority.

Implementation evidence: Ingest OpenAPI 0.7.0 provides the browser policy discovery contract and strict bounds. Unit and Chromium/Firefox/WebKit fixtures prove default-off, masking, stripped attributes/CSS/URLs, private and dynamically inserted subtrees, marker transition fail-closed, shadow DOM exclusion, reconstructable FullSnapshots, bounded memory/queue, frozen retry bodies and cancellation. A snapshot too large for one request stops replay before upload. These tests establish the local SDK behavior, not production workload performance.

Remaining rollout risks: Ingest does not CORS-expose its `Date` header, so arbitrary client clock skew can exceed the true `fresh_until` capture boundary despite the short monotonic lease. The RUM-7F panel must gain the marker before rollout. RUM-7C real E2E remains independently open. Peak JS heap exceeds serialized buffer bytes because object/string/body copies coexist. `npm audit --omit=dev` reported zero production dependency advisories at review time.
